概念校準

MCP 不只是資料庫；它是 Agent 使用專業資料與工具的標準介面

文文件庫：公文、裁罰書、函釋
法法規庫：條文、版本、效期
索索引：案件類型、違規態樣、關鍵事實
≠

MCP 服務＝可被安全調用的「專業能力」

它把資料、提示與工具包成清楚的服務，讓不同的 MCP 相容 Agent 在權限範圍內找到正確內容、執行指定檢核，並留下可追溯結果。

Resources提供可引用的法規、案例與範本
Prompts提供顧問設計的標準作業指令
Tools執行檢索、比對、計算與格式檢查

因此，資料整理仍是基礎；MCP 的差異在於把這些內容變成「有權限、有規格、有輸出格式」的共用服務。

來源：Model Context Protocol｜Server Features OverviewResources・Prompts・Tools

AI 可以協助形成判斷材料，但不得取代依法行政

AI / Agent 可以做

輔助與提醒
  • 擷取文件內容，整理案件事實與時間線
  • 檢索法規、函釋、範本與相似案例
  • 提出缺件、矛盾、引用失效與格式風險
  • 依核准模板產生裁罰書草稿及檢核表

人員必須保留

裁量與責任
  • 確認證據真實性、完整性及證明力
  • 決定法規適用、責任成立與裁量因素
  • 處理例外、爭點、陳述意見及救濟風險
  • 完成簽核、發文、送達與行政責任承擔

建議方向

這不是買一套聊天機器人；而是建立一套機關可以治理、承辦人可以信任的專業工作系統。

選擇試辦架構採 A 的多 Agent 彈性，或以偏好方案 B 統一中央 AI？
確認資料範圍哪些資料可用、需去識別、不得離開機關？
確認預算上限在 150～200 萬元內，以 A 約 162 萬或 B 約 198 萬規劃？
同意評估標準用哪些品質、效率與風險指標判斷是否擴大？
建議下一步：啟動一個可驗證、可停止的 12 週讀取型試辦不是全面上線，也不是先採購大量帳號
